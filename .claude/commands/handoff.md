`docs/SESSION-HANDOFF.md` の `<!-- HANDOFF:BEGIN -->` 〜 `<!-- HANDOFF:END -->` の間を、現在のセッションの引継ぎ状態で上書きしてください。区切り線より上の説明とマーカー自体は変更しないこと。

書く内容（**一時的な文脈のみ**。恒久情報は CLAUDE.md 側なのでここには書かない）:

- **作業中のこと / 中断点:** いま何を途中まで進めたか、次に再開する具体的な一歩。
- **未確定の判断:** 保留中の決定、人の go/no-go 待ち、選択肢が残っている点。
- **直近の状態スナップショット:** 必要なら現時点のビルド/テスト結果や検証済み事項（as-of の値であることを明記）。
- **このセッション固有の環境メモ:** 一時的に効いている設定・回避策など。
- **未コミットの変更:** ある場合はファイルと意図。

ルール:
- git 履歴・CLAUDE.md・コードから辿れる情報は書かない（重複させない）。
- 相対日付は絶対日付に変換する。
- 引継ぎが空なら、無理に埋めず空テンプレート（`_（引継ぎ事項なし。…）_`）のままにする。
- 書き換え後、保存した要点を 2〜4 行でユーザーに報告する。
